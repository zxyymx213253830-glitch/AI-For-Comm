### 阶段四：本地接线与端到端验收

本地改动三件套：

| 文件 | 改动 |
|------|------|
| core/config.py | AGENTS 注册 sim_agent 条目 + requireFullAnswer 指令字段 |
| main.py | sim_kw 关键词路由分支（置于 hw 之后、comm 之前）|
| tests/test_sim_debug.py | 新建验收脚本：质量四校验 → 代码抽取 → 子进程执行 → 理论对照 |

**坑 1：网关通道终答只回收尾语**。第一次实测回复仅 71 字符（"已完成…详细内容见上方输出的…"），四章节正文没进 SSE 流。SSE 抓包（tests/debug_sim_sse.py）证明 gateway 流里只有 thought.delta / message.delta / complete 三种事件，正文从未到达该通道；而体验页 UI 走 `/designer/run` + cmdChannel 通道能渲染全文。两条探针实验给出决定性结论：

- 同样的要求写在**用户问题里** → 完整四章节 3415 字符 ✅
- 只写在线上约束里 → 思考链涨到 382 事件但终答仍只有 91 字收尾语 ❌

对策：调用侧注入 `requireFullAnswer` 后缀（config 定义，main.py 路由与验收脚本统一追加），线上约束保留同类条款作双保险。

**坑 2：生成代码 plt.show() 阻塞**。子进程执行生成的画图代码时 300s 超时（GUI 窗口等待关闭）。对策：`subprocess.run(..., env={**os.environ, "MPLBACKEND": "Agg"})` 无头执行。
