# 科研报告审美技能（靛蓝瓷主题）

把多智能体研究成果渲染成「学术扉页风」HTML 报告时，遵循本规范。灵感来自靛蓝瓷主题：深海军蓝 + 琥珀金点缀，克制、庄重、有呼吸感。

## 一、设计令牌（必须照抄）

```css
:root {
  --ink: #0a1f3d;        /* 靛蓝：主背景 / 扉页 */
  --ink-tint: #152a4a;   /* 靛蓝浅一档：卡片、分割 */
  --paper: #f1f3f5;      /* 纸色：正文区背景 */
  --paper-tint: #e4e8ec; /* 纸色加深：表格斑马、引用块 */
  --gold: #c9973f;       /* 琥珀金：强调、徽章、时间轴节点 */
  --text: #1a2332;       /* 正文墨色 */
  --muted: #5b6472;      /* 次要文字 */
  --serif: "Songti SC", "STSong", "SimSun", serif;      /* 展示字体：大标题 */
  --sans: "PingFang SC", "Microsoft YaHei", sans-serif; /* 正文 */
  --mono: "JetBrains Mono", "Consolas", monospace;      /* 代码 */
}
```

## 二、版式硬规则

1. **扉页**：满版靛蓝底 + 衬线大标题（课题名，≤32 字可换行）+ 琥珀金评级徽章 + 关键词 + 元信息栏（日期 / 流水线 / 模型）。
2. **章节编号**：两位数字前缀（00 执行摘要，01–06 正文章节），衬线字体、琥珀金色。
3. **时间轴**：协作链路用竖向时间轴，节点圆点琥珀金，标注 Agent 名与耗时。
4. **正文行宽**：≤720px 居中，行高 1.8，段间距大于行距。
5. **公式**：KaTeX 渲染，代码等宽字体；公式块上下留白 ≥24px。
6. **附录**：专家原文放 `<details>` 折叠，标题带 Agent 名，避免喧宾夺主。
7. **打印**：`@media print` 隐藏动效、扉页不分页截断（`page-break-inside: avoid`）。
8. **动效克制**：只允许淡入（≤300ms），尊重 `prefers-reduced-motion`。

## 三、禁止清单

- 禁止彩虹渐变、霓虹色、大圆角卡片堆叠（圆角 ≤6px）。
- 禁止 Emoji 做章节图标，用数字编号。
- 禁止把专家原文平铺进正文，必须走折叠附录。
- 禁止在正文出现「如上所述」「见上文」等指代词。

## 四、交付前自检

- [ ] 扉页四要素齐：课题 / 评级 / 关键词 / 元信息
- [ ] 所有公式已渲染，无 `$` 残留
- [ ] 评级徽章颜色与结论一致（通过=金、待改进=蓝、不通过=灰红）
- [ ] 打印预览无截断、无黑底浪费墨
- [ ] 全文 ≤15 屏，执行摘要 ≤300 字
