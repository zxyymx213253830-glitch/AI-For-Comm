math_agent 数学推导结果
【已知条件】 - 信道类型：AWGN - 带宽 B = 20 MHz = 20 × 10^6 Hz - 信噪比 SNR = 30 dB 【使用公式】 香农信道容量公式（引自知识库 01_香农信道容量公式.md，Shannon 1948, Eq. (38)）： C = B · log₂(1 + S/N) 【代入计算】 - SNR 线性值: S/N = 10^(30/10) = 1000 - log₂(1+1000) = log₂(1001) ≈ 9.968 - C = 20×10^6 × 9.968 ≈ 1.994×10^8 bps ≈ 199.4 Mbps
