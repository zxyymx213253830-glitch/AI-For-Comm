math_agent 数学推导结果
【已知条件】 - 信道类型：AWGN（加性高斯白噪声信道） - 带宽 B = 20 MHz = 20 × 10⁶ Hz - 信噪比 SNR = 30 dB 【使用公式】 香农信道容量公式（引自知识库 `01_香农信道容量公式.md` 及 Shannon 1948, Theorem 2）： C = B · log₂(1 + S/N) [bps] dB 与线性值转换公式（引自同一知识库）： SNR_linear = 10^(SNR_dB / 10) 【推导过程】 第 1 步：单位与信噪比换算 - 带宽：B = 20 × 10⁶ Hz - SNR 线性值：SNR_linear = 10^(30 / 10) = 10³ = 1000 第 2 步：代入香农公式 C = 20 × 10⁶ × log₂(1 + 1000) C = 20 × 10⁶ × log₂(1001) 第 3 步：计算对数项（换底公式，保留 4 位有效数字） log₂(1001) = ln(1001) / ln(2) ln(1001) ≈ 6.9088 ln(2) ≈ 0.6931 log₂(1001) ≈ 6.9088 / 0.6931 ≈ 9.968 第 4 步：计算最终容量（保留中间过程 4 位有效数字） C ≈ 20 × 10⁶ × 9.968 C ≈ 199.36 × 10⁶ bps C ≈ 199.4 Mbps 【边界检验】 - SNR→0 时，log₂(1)→0，容量 C→0 ✓ - SNR→∞ 时，log₂(1+SNR)≈log₂(SNR)，C≈B·log₂(SNR) ✓ - B→0 时，C→0 ✓ 【最终结果】 AWGN 信道容量 C ≈ 199.4 Mbps 【物理意义】 在 20 MHz 带宽和 30 dB 高信噪比条件下，理论无差错传输速率上限约为 199.4 Mbps。此时频谱效率 η = C/B ≈ 9.97 bps/Hz。实际通信系统受限于调制编码方案（MCS）及实现损耗，通常只能达到该理论值的 70%~85%。边界检验通过，推导无误。
