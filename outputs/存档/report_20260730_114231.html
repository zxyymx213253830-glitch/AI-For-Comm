math_agent 数学推导结果
【已知条件】 - 信道类型：AWGN - 带宽 B = 20 MHz = 20 × 10^6 Hz - 信噪比 SNR = 30 dB 【使用公式】 香农信道容量公式（引自知识库 01_香农信道容量公式.md，Shannon 1948 Eq. (38)）： C = B · log₂(1 + S/N) 【推导过程】 第 1 步：dB → 线性值换算 SNR_linear = 10^(SNR_dB / 10) = 10^(30/10) = 10^3 = 1000.0 第 2 步：代入香农公式 C = B · log₂(1 + SNR_linear) C = 20 × 10^6 · log₂(1 + 1000.0) C = 20 × 10^6 · log₂(1001.0) 第 3 步：计算 log₂(1001) 根据换底公式：log₂(x) = ln(x) / ln(2) log₂(1001) = ln(1001) / ln(2) ≈ 6.9088 / 0.6931 ≈ 9.9672 第 4 步：最终计算 C = 20 × 10^6 × 9.9672 C = 199.34 × 10^6 bps 按3位有效数字修约：C ≈ 199 Mbps 【最终结果】 信道容量 C ≈ 199 Mbps 【物理意义】 该结果表明在20 MHz带宽与30 dB高信噪比条件下，该AWGN信道的理论极限传输速率约为199 Mbps，验证了香农极限对系统设计的约束作用。
