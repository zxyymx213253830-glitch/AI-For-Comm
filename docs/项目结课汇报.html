01项目概述

让 7 个各司其职的 AI 智能体像一个科研小组一样协作，把「给出一个通信课题 → 自动产出一份经过交叉校验、含真实仿真图表的研究报告」这件事全流程打通。系统采用「大脑在平台、手脚在本地」的混合架构：智能体推理与知识库检索由 OpenTrek 平台承载，真实计算执行、代码沙箱、报告渲染与 Web 应用由本地落地，两侧通过标准接口解耦。

要解决的三个硬伤

单一大模型的硬伤本系统对症机制
推导易错、没人复核独立校验智能体 + 三级评级 + 不通过自动退回修正（闭环 ≤2 轮）
「仿真结果」可能是编的仿真真执行闭环：代码必须在本地沙箱真实跑通，结果回灌后才许出图
产出格式散落不可用固定字段 JSON 统稿协议 + 高审美 HTML 渲染引擎，产出即交付

六步流水线

步骤执行者产出
1 规划拆题规划者角色课题拆成 2~5 个带专家归属的子问题（JSON）
2 文献调研文献调研智能体公网（arXiv / Semantic Scholar）+ 平台知识库双源综述
3 并行咨询数学/协议/硬件/仿真专家各子问题专家答案，同一专家至多领 1 题，并发执行
4 交叉校验校验智能体三级评级：【通过】/【有条件通过】/【不通过】
5 闭环修正原专家智能体不通过按反馈修正重提，至多 2 轮
6 统稿成报报告主编智能体 + 本地渲染引擎固定字段 JSON → 靛蓝瓷主题 HTML 研究报告（内嵌仿真图表）

三个关键机制

  • 仿真真执行闭环——仿真智能体出代码，本地沙箱真实运行（临时目录隔离、无窗口绘图、中文字体预置），运行结果回灌智能体，与理论公式同图对照后才出图，从制度上杜绝「编造运行结果」。
  • 工具回环协议——本地工具清单注入提示词，智能体按需申请调用，执行结果回喂继续推理。
  • 知识库挂载——调用时按配置声明自动携带知识库检索参数，数学/协议/硬件/文献智能体各挂对应领域库。

04本地侧建设情况

核心框架（core/，10 模块）

智能体通用节点（会话管理 / SSE 流解析 / 空回复重试）、六步研究流水线、双智能体协作编排器、内存消息总线、工具回环驱动、报告 HTML 渲染引擎、配置管理器（Web 设置页可视化编辑并热写配置）、结构化日志。

本地工具层（tools/，7 项，离线验收 30/30 通过）

  • SymPy 符号计算与等式复核；通信算法库（调制、信噪比换算、理论误码率与容量——16QAM 公式已修正为精确积分式并经蒙特卡洛验证）
  • Python 代码沙箱（临时目录隔离、无窗口绘图、图表回收；代码提取支持围栏 / 无语言围栏 / 章节缩进 / 裸代码回退四形态）
  • Verilog 本地编译仿真、arXiv 与 Semantic Scholar 文献检索、本地资料毫秒级检索、工具注册表（中文标签直达前端徽标）

Web 应用（web/，6 页全中文界面）

实时对话（SSE 流式）、研究流水线执行页（步骤进度 + 3D 协作网络动画）、报告库（在线查看/下载，公式渲染 + 代码高亮）、智能体监控看板、设置页（平台连接与凭证管理）。设计系统为深海军蓝 / 琥珀金主题，配套自研 logo。

通信仿真专项

  • 仿真模板 6 类全部落地并经本地数值验证：AWGN 误码率蒙特卡洛、香农信道容量、数字调制星座图、瑞利衰落、MIMO 容量、信道编码增益，另有绘图与实验规范 1 篇
  • 标杆案例：BPSK 在 AWGN 信道误码率全链路——理论推导 → 蒙特卡洛仿真真执行 → 理论曲线同图对照 → 校验通过 → 入报告
  • 图表自动嵌入：流水线生成的 PNG 自动回收并内嵌最终 HTML 报告

提示词工程（prompts/，与平台在线版同源同步）

五份角色手册 + 五份硬约束文件。09-02 并入交付包新规范：数学「推导三步法」（推导→符号复算→边界检验）与校验「通用四项清单」（量纲 / 单调性 / 特殊值代入 / 文献对照），已直调平台配置接口上线并回读验证。

部署与运行环境

Docker / Compose 容器化定义齐备；内网演示环境服务常驻 7860 端口、防火墙放行、局域网可访；校园网零信任环境的会话过期问题已完成诊断与穿透预案。

工程攻坚（沉淀为可复用经验）

  • 平台 180 秒硬超时：截断抢救 + 本地机械统稿兜底
  • SSE 终答不全：思考链回退 + 调用侧指令注入双保险
  • 代码围栏截断：平台输出与本地提取联合修复
  • 子进程绘图阻塞：无窗口后端强制预防
  • 提示词 token 耗尽：极简角色手册重构（v7.2 经验）
  • 平台多版本并存：调用侧显式版本锁定策略
