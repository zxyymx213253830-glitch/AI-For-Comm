# 信息论核心不等式与证明工具

## 别名
信息不等式、Information Inequalities、Fano's Inequality、数据处理不等式、KL散度、Jensen不等式

---

## 概述

信息论中的大量定理依赖一组核心不等式和工具。掌握它们是理解证明、推导新结论和判断信息论主张对错的基础。

---

## 一、Jensen 不等式

### 1.1 定理

> 对于凸函数 f(x)（即 f''(x) ≥ 0）：
> ```
> f(E[X]) ≤ E[f(X)]
> ```

### 1.2 信息论中的应用

**取 f(x) = -log x（凸函数）**，立即得到熵的非负性证明：

```
H(X) = E[-log p(X)] = E[f(p(X))] ≥ f(E[p(X)]) = -log(Σpᵢ²)

由于 Σpᵢ² ≤ 1（平方和不超过本身的概率），所以：
  H(X) ≥ -log(1) = 0  ✓
```

### 1.3 熵的上界证明

```
H(X) = Σ pᵢ log(1/pᵢ) ≤ log(Σ pᵢ·(1/pᵢ)) = log N

（利用 f=log 的凹性 + Jensen 不等式）
当且仅当所有 pᵢ 相等时取等号
```

## 二、KL 散度（相对熵）

### 2.1 定义

```
D_KL(P || Q) = Σ P(x)·log(P(x)/Q(x))

性质：
  1. D_KL(P || Q) ≥ 0（Gibbs 不等式）
  2. D_KL(P || Q) = 0 ⟺ P = Q（几乎处处）
  3. D_KL(P || Q) ≠ D_KL(Q || P)（不对称！）
  4. D_KL(P || Q) 不是真正的距离度量
```

### 2.2 KL 散度与互信息的关系

```
I(X;Y) = D_KL(P(x,y) || P(x)·P(y))

→ 互信息 = 联合分布与独立分布之间的 KL 散度
→ 度量 X 和 Y 之间的"非独立性"
```

### 2.3 例题

**题目**：抛一枚硬币，实际正面概率 p=0.7，但你错误地认为它公平 (q=0.5)。这个错误认知的"代价"(KL 散度) 是多少？

**解**：
```
D_KL(p || q) = 0.7·log₂(0.7/0.5) + 0.3·log₂(0.3/0.5)
             = 0.7·log₂(1.4) + 0.3·log₂(0.6)
             = 0.7·0.485 + 0.3·(-0.737)
             ≈ 0.339 - 0.221
             ≈ 0.118 bit
```

## 三、数据处理不等式

### 3.1 定理

> 若 X → Y → Z 构成马尔可夫链（Z 仅通过 Y 依赖 X）：
> ```
> I(X;Y) ≥ I(X;Z)
> ```

### 3.2 物理含义

```
X ──→ [处理1: Y] ──→ [处理2: Z]

→ 每经过一次处理，关于 X 的信息量不会增加
→"数据处理不会创造信息"
→"Garbage in, garbage out" 的数学证明
```

### 3.3 推论：充分统计量

若 Y 是 X 的充分统计量（即 Z = g(Y) 的任意处理后 I(X;Y) = I(X;Z)），则 Y 保留了 X 的全部信息。

```
例子：
  X = 邮件内容的原始字节流
  Y = 邮件词频向量（充分统计量）
  Z = 仅前 3 个词的频率（不充分）
  
  I(X;Y) = I(X;原始内容) — Y 保留了全部信息
  I(X;Z) < I(X;Y)         — Z 丢失了信息
```

## 四、Fano 不等式

### 4.1 定理

设 ^X 是 X 通过观测 Y 的估计，P_e = Pr(^X ≠ X)：

```
H(P_e) + P_e·log(|X|-1) ≥ H(X|Y)

特例（|X|=2 二元估计）：
  H(P_e) ≥ H(X|Y)
```

### 4.2 最重要的推论——信道编码逆定理

```
对离散无记忆信道，若 R > C：
  H(X|Y) ≥ H(X) - I(X;Y) ≥ nR - nC = n(R-C) > 0

代入 Fano 不等式：
  H(P_e) + P_e·log(2^(nR)-1) ≥ n(R-C)
  → P_e ≥ (n(R-C) - 1) / (nR)

当 n → ∞ 时，P_e → (R-C)/R > 0

→ 如果 R > C，错误概率不会趋于零！
→ 这就是信道编码定理的逆命题证明
```

### 4.3 例题

**题目**：二元对称信道（BSC），交叉概率 0.1，使用 R=0.5 的编码方案。Fano 不等式给出的最小错误概率下界是？

**解**：
```
BSC(0.1) 容量：C = 1 - H(0.1) = 1 - 0.469 = 0.531

R = 0.5 < C = 0.531 → 不可能用 Fano 给出有意义的 P_e 下界
（Fano 只给出 R > C 时的下界）

若 R = 0.6 > C = 0.531：
  n → ∞ : P_e ≥ (0.6 - 0.531)/0.6 ≈ 0.115
  即至少有约 11.5% 的概率出错
```

## 五、对数和不等式 (Log-Sum Inequality)

### 5.1 定理

```
对于非负序列 aᵢ, bᵢ：

Σ aᵢ·log(aᵢ/bᵢ) ≥ (Σ aᵢ)·log(Σ aᵢ / Σ bᵢ)

等号成立当且仅当 aᵢ/bᵢ = 常数
```

### 5.2 应用：KL 散度的凸性

对数和不等式直接推出：

```
D_KL(λP₁ + (1-λ)P₂ || λQ₁ + (1-λ)Q₂) ≤ λD_KL(P₁||Q₁) + (1-λ)D_KL(P₂||Q₂)

→ KL 散度在 (P,Q) 上联合凸
→ 互信息 I(X;Y) 在 p(x|y) 上凸、在 p(x) 上凹
```

## 六、熵的链式法则

### 6.1 基本链式法则

```
H(X₁, X₂, ..., Xₙ) = H(X₁) + H(X₂|X₁) + ... + H(Xₙ|X₁,...,Xₙ₋₁)
                   = Σ H(Xᵢ|X₁,...,Xᵢ₋₁)
```

### 6.2 互信息的链式法则

```
I(X₁,...,Xₙ; Y) = I(X₁;Y) + I(X₂;Y|X₁) + ... + I(Xₙ;Y|X₁,...,Xₙ₋₁)
                = Σ I(Xᵢ; Y | X₁,...,Xᵢ₋₁)
```

### 6.3 条件不增加熵

```
H(X|Y) ≤ H(X)           — 条件不增加熵
I(X;Y|Z) ≥ 0            — 条件互信息非负
H(X|Y,Z) ≤ H(X|Y)       — 更多条件减少不确定性
```

## 七、渐近均分性 (AEP) 与典型集

### 7.1 AEP 定理

对于 n 个 i.i.d. 随机变量 X₁,...,Xₙ ~ p(x)：

```
-(1/n)·log p(X₁,...,Xₙ) → H(X)   (依概率收敛)
```

### 7.2 典型集

```
A_ε^(n) = {xⁿ : |-(1/n)·log p(xⁿ) - H(X)| < ε}

性质（"典型集三件套"）：
  1. Pr(A_ε^(n)) → 1          （几乎必然落入典型集）
  2. |A_ε^(n)| ≈ 2^(nH)       （典型集大小约 2^(nH)）
  3. 典型序列概率 ≈ 2^(-nH)    （每个典型序列等概率）
```

### 7.3 AEP 是信息论的"引擎"

几乎所有信息论定理的证明都依赖典型集：

```
信源编码定理证明：
  → 只需编码典型集中的 ≈ 2^(nH) 个序列
  → 需要约 nH 比特
  → 非典型集概率 → 0，可以忽略

信道编码定理证明：
  → 随机生成 2^(nR) 个码字
  → 对于每个接收序列，联合典型的发送码字平均有 2^(n(R-I(X;Y))) 个
  → 当 R < I(X;Y) = C 时，这个数 → 0
  → 解码成功！
```

## 八、信息论不等式速查表

| 不等式 | 公式 | 等号条件 | 用途 |
|--------|------|---------|------|
| **熵的非负性** | H(X) ≥ 0 | X 确定 | 基本性质 |
| **熵的上界** | H(X) ≤ log N | 等概 | 最大熵原理 |
| **KL 非负** | D(P\|\|Q) ≥ 0 | P=Q | 万能证明工具 |
| **数据处理** | I(X;Y) ≥ I(X;Z) | 充分统计量 | 证明信息不会凭空增加 |
| **Fano** | H(P_e) + P_e·log(N-1) ≥ H(X\|Y) | — | 信道编码逆定理 |
| **条件不增熵** | H(X\|Y) ≤ H(X) | X⊥Y | 条件减少不确定性 |
| **并集界** | H(X,Y) ≤ H(X) + H(Y) | X⊥Y | 联合熵的上界 |
| **对数和** | Σ aᵢ·log(aᵢ/bᵢ) ≥ (Σaᵢ)·log(Σaᵢ/Σbᵢ) | aᵢ/bᵢ=常数 | 凸性证明 |
| **互信息非负** | I(X;Y) ≥ 0 | X⊥Y | 基本性质 |

## 九、用这些工具证明：AWGN 信道容量公式

作为综合练习，展示如何用上述工具推导 C = (1/2)·log₂(1+SNR)（复基带 AWGN，单位带宽）：

```
输入 X ~ CN(0, P)
噪声 Z ~ CN(0, N)
输出 Y = X + Z

I(X;Y) = h(Y) - h(Y|X)
       = h(Y) - h(Z)           （因为 Y|X ~ CN(X, N), 微分熵平移不变）
       = h(Y) - log₂(πeN)      （复高斯微分熵公式）

由于 Y ~ CN(0, P+N):
  h(Y) = log₂(πe(P+N))

所以：
  I(X;Y) = log₂(πe(P+N)) - log₂(πeN)
         = log₂(1 + P/N)

最大化（输入功率约束 E[|X|²] ≤ P）：
  高斯分布是给定方差下最大化微分熵的分布（由 KL 非负可证）
  → X = CN(0, P) 最优

  C = max I(X;Y) = log₂(1 + P/N) = log₂(1 + SNR)
     p(x)
```
