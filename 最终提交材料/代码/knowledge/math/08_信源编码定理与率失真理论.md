# 信源编码定理与率失真理论

## 别名
Source Coding Theorem、无损压缩极限、Rate-Distortion Theory、有损压缩理论、香农三大定理

---

## 一、香农三大定理总览

在深入细节之前，先建立整体框架。香农 1948 年的论文奠定了三条核心定理：

| 定理 | 英文 | 研究的信道 | 核心结论 |
|------|------|----------|---------|
| **第一定理** | Source Coding Theorem | 无噪信道 | 压缩极限 = 信源熵 H(X) |
| **第二定理** | Channel Coding Theorem | 有噪信道 | 可靠传输速率 ≤ 信道容量 C |
| **第三定理** | Rate-Distortion Theorem | 有噪信道 + 失真容忍 | 有损压缩极限 = R(D) 函数 |

```
信源 ──[第一定理]──→ 压缩 ──[第二定理]──→ 传输 ──→ 解压

       ┌──[第三定理]──→ 有损压缩（跳过无损瓶颈）──┐
       └──────────────────────────────────────────┘
```

## 二、香农第一定理：无噪信源编码定理

### 2.1 定理陈述

> 对于熵为 H 的离散无记忆信源，存在一种编码方案使平均码长 L 满足：
> ```
> H ≤ L < H + 1
> ```
> 且 H 是任何唯一可译码的平均码长下界。

### 2.2 物理含义

- **H 是压缩的硬极限**——不可能把信源压缩到平均每符号少于 H 比特
- 超过 H 的部分都是"浪费"——信源中的冗余
- 英文文本的熵约 1.0-1.5 bit/字符（包含 26 字母），这说明英文文本理论上可被压缩到当前大小的约 1/5

### 2.3 Kraft 不等式

前缀码存在的充要条件：

```
Σ 2^(-lᵢ) ≤ 1

其中 lᵢ 是第 i 个码字的长度
```

### 2.4 典型编码方案

| 方案 | 平均码长 | 是否为前缀码 | 是否最优 |
|------|---------|-----------|---------|
| **香农码** | lᵢ = ⌈-log₂ pᵢ⌉ | 是 | 在 1 bit 内最优 |
| **霍夫曼码** | H ≤ L < H+1 | 是 | **最优前缀码** |
| **算术编码** | 任意接近 H | 是 | 渐近最优 |
| **LZ77/LZ78** | 渐近 H（未知分布） | N/A | 无需知道信源分布 |

### 2.5 例题

**题目**：信源输出 A, B, C, D 概率分别为 [0.5, 0.25, 0.125, 0.125]。求熵和最优平均码长。

**解**：
```
H = -[0.5·log₂0.5 + 0.25·log₂0.25 + 2×0.125·log₂0.125]
  = -[0.5·(-1) + 0.25·(-2) + 0.25·(-3)]
  = 0.5 + 0.5 + 0.75
  = 1.75 bit/符号

霍夫曼编码：
  A: 0      (1 bit)
  B: 10     (2 bits)
  C: 110    (3 bits)
  D: 111    (3 bits)

平均码长 L = 0.5×1 + 0.25×2 + 0.125×3 + 0.125×3
           = 0.5 + 0.5 + 0.375 + 0.375
           = 1.75 bit/符号

完美！L = H，达到了理论下界。
```

## 三、香农第三定理：率失真理论

### 3.1 为什么需要率失真

第一定理说压缩不能低于 H——但这只适用于**无损**压缩。实际中很多时候可以容忍一定失真，换来更高的压缩比。

**例子**：
- JPEG 压缩图片：肉眼几乎看不出差异，但文件小了 10 倍
- MP3 音频：丢掉人耳听不到的频率成分
- 视频会议：允许偶尔的模糊帧，换取流畅度

### 3.2 率失真函数 R(D)

```
R(D) = min_{p(^x|x): E[d(x,^x)] ≤ D} I(X; ^X)

其中：
  D: 允许的最大失真
  d(x, ^x): 失真度量函数
  I(X; ^X): 原始信号与重建信号之间的互信息
```

**物理含义**：在允许失真 D 的前提下，压缩后的每符号最少需要多少比特。

### 3.3 常见失真度量

| 度量 | 公式 | 适用 |
|------|------|------|
| **汉明失真** | d(x, ^x) = 1(x ≠ ^x) | 离散符号（字符、比特） |
| **平方误差** | d(x, ^x) = (x - ^x)² | 连续信号（图像、音频） |
| **绝对误差** | d(x, ^x) = |x - ^x| | 鲁棒估计 |

### 3.4 高斯信源的率失真函数

**经典结果**：对于方差 σ² 的高斯信源 + 平方误差失真度量：

```
R(D) = { (1/2)·log₂(σ²/D),  0 ≤ D ≤ σ²
       { 0,                  D > σ²
```

```
可视化：

R(D)
↑
|⧹
|  ⧹
|    ⧹
|      ⧹__________→ D
0       σ²
```

- 当 D → 0（要求无损），R → ∞（连续信源不可能无损压缩）
- 当 D → σ²（允许失真等于信号方差），R → 0（不需要传输任何信息——直接猜均值就行）
- D = σ²/4 时，R = 1 bit/样点

### 3.5 例题

**题目**：高斯信源 σ²=4，允许平方误差失真 D=1，求最少需多少比特每样点。

**解**：
```
R(D) = (1/2)·log₂(σ²/D) = (1/2)·log₂(4/1) = (1/2)·2 = 1 bit/样点
```

## 四、香农第二定理：有噪信道编码定理

### 4.1 定理陈述

> 对于容量为 C 的离散无记忆信道，若速率 R < C，则存在编码方案使错误概率任意小。
> 若 R > C，则任何编码方案都无法实现可靠通信。

### 4.2 三大定理的关系图

```
          信源                     信道
     ┌─────────────┐         ┌─────────────┐
     │  H(X) bits  │         │  C bps/Hz   │
     │  (熵)       │         │  (容量)      │
     └──────┬──────┘         └──────┬──────┘
            │                       │
     ┌──────▼──────┐         ┌──────▼──────┐
     │ 第一定理     │         │ 第二定理     │
     │ 压缩率 ≥ H   │         │ R < C 可通  │
     └──────┬──────┘         └──────┬──────┘
            │                       │
            └───────────┬───────────┘
                        │
                ┌───────▼───────┐
                │ 分离定理       │
                │ 信源编码和      │
                │ 信道编码可分开  │
                │ 设计 (不损失    │
                │ 最优性)        │
                └───────────────┘
```

### 4.3 分离定理 (Separation Theorem)

香农证明了：**把信源编码和信道编码拆开设计，不会损失最优性**。

```
信源 → [压缩到 H] → [编码到 C] → 信道 → [解码] → [解压缩] → 信宿

只要 H < C，就能可靠传输。
```

> ⚠️ **实际系统中分离定理不成立**：有限延迟、时变信道、多用户场景下，**联合信源信道编码 (JSCC)** 可能更优。这也是为什么 5G URLLC 和语义通信需要重新审视这个假设。

## 五、量化理论（连续→离散）

### 5.1 标量量化

将连续值映射到有限个离散值：

```
Q(x) = qᵢ,  当 x ∈ [bᵢ₋₁, bᵢ)

量化误差：e = x - Q(x)
```

| 量化器类型 | 特点 |
|-----------|------|
| **均匀量化** | 区间等宽，简单，对均匀分布最优 |
| **Lloyd-Max 量化** | 根据分布优化区间边界和重建值 |
| **熵约束量化** | 在率失真框架下优化 |

### 5.2 高分辨率量化近似

对于平滑分布的标量量化器，每增加 1 bit 分辨率，失真约减少 6 dB：

```
当 R 较大时（高分辨率）：
  标量量化：D(R) ≈ (1/12)·2^(-2R) （均匀量化）
  向量量化：D(R) ≈ c·2^(-2R)      （可达到率失真界）
```

## 六、附：有限块长信息论（5G URLLC 的理论基础）

经典信息论假设**码长无限**（n → ∞）。URLLC 需要**短包**（几十到几百比特）下的可靠传输。

Polyanskiy et al. (2010) 给出了有限块长下的可达速率：

```
R(n, ε) ≈ C - √(V/n)·Q^(-1)(ε) + O(log n / n)

其中：
  n: 码长
  ε: 目标错误概率
  V: 信道色散 (channel dispersion)
  Q^(-1): 标准正态逆 CDF
```

**关键结论**：要达到 C 的 90%（ε=10⁻³），n 需要约 500-1000 符号。
