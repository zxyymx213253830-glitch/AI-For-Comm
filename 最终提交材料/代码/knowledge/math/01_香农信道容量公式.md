# 香农信道容量公式

## 别名
香农极限、Shannon capacity、Shannon-Hartley theorem、信道最大传输速率、信道容量上限

---

## 一、核心公式

```
C = B · log₂(1 + S/N)     [bps]

其中：
  C: 信道容量 (bits per second)
  B: 信道带宽 (Hz)
  S: 信号平均功率 (W)
  N: 噪声平均功率 (W)
  S/N: 线性信噪比（无量纲）
```

### dB 与线性值转换

```
SNR_dB = 10 · log₁₀(SNR_linear)
SNR_linear = 10^(SNR_dB / 10)
```

| dB | 线性值 | dB | 线性值 |
|----|--------|-----|--------|
| 0 dB | 1 | 20 dB | 100 |
| 3 dB | 2 | 23 dB | 200 |
| 6 dB | 4 | 26 dB | 400 |
| 10 dB | 10 | 30 dB | 1000 |
| 13 dB | 20 | 40 dB | 10000 |

---

## 二、适用条件

1. **AWGN 信道**——加性高斯白噪声，噪声统计特性稳定
2. **连续时间、功率受限**——平均发射功率上限为 S
3. **无带宽外约束**——仅带宽 B 和功率 S 构成物理约束
4. **理想编码假设**——允许无限长码、无限计算复杂度

---

## 三、公式含义

```
物理直觉：

  B      → 每秒可发送多少个独立"信号维度"(符号)
  log₂(1+S/N) → 每个维度能携带多少可靠信息 (bits/dim)
  C      = 维度数 × 每维度信息量

三个关键推论：

1. R < C  → 存在一种编码方案使误码率任意趋近于零
2. R > C  → 不可能实现可靠通信（无论用什么编码）
3. R = C  → 可以逼近，但需要无限码长 + 最优编码
```

---

## 四、推导（从信息论角度）

```
AWGN 信道模型：
  Y = X + Z,  Z ~ N(0, N)

互信息容量定义：
  C = max_{p(x): E[X²] ≤ S} I(X;Y)

由互信息的定义：
  I(X;Y) = h(Y) - h(Y|X) = h(Y) - h(Z)  (Z 与 X 独立)

h(Z) = (1/2)·log₂(2πeN)  （高斯微分熵）

h(Y) ≤ (1/2)·log₂(2πe(S+N))  （等号当 X 高斯时成立，因高斯分布
                                  在方差约束下最大化微分熵）

因此：
  C = (1/2)·log₂(1 + S/N)   [bits per real dimension]

对于复基带（两维/符号），采样率 B：
  C = B · log₂(1 + S/N)     [bps]
```

## 五、香农极限的推导（Eb/N₀ 视角）

从能效角度看香农极限：

```
令 R = C (以容量速率传输)：

C/B = log₂(1 + S/N) = log₂(1 + (R·Eb)/(B·N₀))
                                           ↑ S = R·Eb (每秒能量)
                                           ↑ N = B·N₀ (带宽内噪声功率)

令 η = C/B (频谱效率):

η = log₂(1 + η·Eb/N₀)

解出：
  Eb/N₀ = (2^η - 1) / η

当 η → 0 (无限带宽极限), 由洛必达法则：
  Eb/N₀ → ln(2) ≈ 0.693 → -1.59 dB

这就是传说中的 "香农极限" — 可靠通信所需的最小 Eb/N₀
```

| 频谱效率 η (bps/Hz) | 香农极限 Eb/N₀ (dB) |
|---------------------|---------------------|
| 0.1 | -1.53 |
| 0.5 | -1.21 |
| 1.0 | 0.00 |
| 2.0 | 2.97 |
| 4.0 | 7.09 |
| 6.0 | 10.71 |
| 8.0 | 14.11 |

## 六、带宽-信噪比的折衷

```
香农公式揭示：B 和 SNR 可以互换

固定 C，若 B 翻倍：
  需要的 SNR 从 S/N 降为 √(S/N) ≈ 原 SNR/2

固定 C，若 B 减半：
  需要的 SNR 从 S/N 升为 (S/N)²

极端情况：
  B → ∞ : C → 1.44·S/N₀  (功率极限)
  S → ∞ : C → ∞          (功率不受限时容量无上界)
```

## 七、实用扩展

### 7.1 频率选择性信道（OFDM 水填充）

宽带信道可分解为 K 个并行窄带子信道：

```
C = Σ Bₖ · log₂(1 + Pₖ·|hₖ|² / N₀)

最优功率分配（水填充）：
  Pₖ = max(0, μ - N₀/|hₖ|²)
  其中 μ 满足 ΣPₖ = P_total
```

### 7.2 衰落信道容量

| 概念 | 定义 | 含义 |
|------|------|------|
| **遍历容量** | E_h[C(h)] | 快衰落下长期平均可达速率 |
| **中断容量** | max{R: Pr[C(h) < R] ≤ ε} | 慢衰落下 ε-中断概率时的最大速率 |
| **CSIT 容量** | 发端知信道时可做自适应调制/功率控制 | 通常比 CSIR-only 高 |

对于 Rayleigh 衰落 (|h|² ~ exp(1))，低 SNR 下：

```
C_ergodic ≈ SNR·E[|h|²]·log₂(e) = SNR·log₂(e)  (与 AWGN 相同！)

但在高 SNR 下：
  C_ergodic ≈ log₂(SNR) + E[log₂|h|²]  
             = log₂(SNR) - γ_Euler/log(2)   ≈ log₂(SNR) - 0.83
           （衰落带来约 0.83 bit 的固定损失，而非因子损失）
```

### 7.3 MIMO 信道容量

Nt 发射天线、Nr 接收天线：

```
C = log₂ det (I + (SNR/Nt)·H·H^H)

高 SNR 近似：C ≈ min(Nt,Nr)·log₂(SNR)
→ 容量随天线数线性增长！
```

详见 `07_MIMO信道容量与空时编码.md`。

## 八、典型例题

### 例题 1（基础）
某 AWGN 信道带宽 20MHz，信噪比 30dB，求信道容量。

```
SNR_linear = 10^(30/10) = 1000
C = 20×10⁶ × log₂(1 + 1000) = 20×10⁶ × log₂(1001)
log₂(1001) = ln(1001)/ln(2) ≈ 6.9078/0.6931 ≈ 9.967
C ≈ 20×10⁶ × 9.967 ≈ 199.34 Mbps
```

### 例题 2（带宽加倍）
带宽加倍 (B=40MHz)，SNR 不变 (30dB)。

```
C = 40×10⁶ × log₂(1001) ≈ 398.68 Mbps
→ 容量恰好翻倍（频谱效率不变）
```

### 例题 3（带宽减半但功率加倍）
B=10MHz，SNR 变为 33dB（功率翻倍）。

```
SNR_linear = 10^(33/10) = 1995.3
C = 10×10⁶ × log₂(1 + 1995.3) ≈ 10×10⁶ × 10.96 ≈ 109.6 Mbps

对比原方案 (199.3 Mbps)：
  虽然 SNR 翻倍，但 B 减半，
  由于 log₂(1+2S/N) < 2·log₂(1+S/N)
  → 带宽减半的损失 > SNR 翻倍的补偿
  → 香农公式中 B 和 SNR 不是完全对称的！
```

### 例题 4（香农极限检验）
若系统要求频谱效率 η=2 bps/Hz，理论所需最低 Eb/N₀ 是多少？

```
解 Eb/N₀ = (2^η - 1)/η = (2² - 1)/2 = 3/2 = 1.5 → 1.76 dB

实际 5G NR LDPC 码在 η=2 bps/Hz, BER=10⁻⁵ 时约需 4-5 dB
→ 距理论极限约 2.5-3.5 dB（这是编码设计的进步空间）
```

### 例题 5（带宽换功率的极端案例）
GPS 信号：B ≈ 2 MHz，SNR ≈ -26 dB（信号功率远低于噪声）。求理论最大信息速率。

```
SNR_linear = 10^(-26/10) ≈ 0.0025
C = 2×10⁶ × log₂(1.0025) ≈ 2×10⁶ × 0.0036 ≈ 7.2 kbps

实际 GPS C/A 码速率 = 50 bps（远低于容量，因为它不需要高速率，
但利用扩频在极低 SNR 下可靠传输——这正是香农公式中"带宽换SNR"的体现）
```

## 九、常见误区

| 误区 | 纠正 |
|------|------|
| "容量只取决于 SNR" | 带宽 B 和 SNR 同等重要，且不可完全互换 |
| "提高发射功率就一定能提高容量" | 在高 SNR 区，log₂ 增长极慢，加倍功率可能只换来 1 bps/Hz |
| "香农公式适用于任何信道" | 仅适用于 AWGN——衰落/干扰信道有各自的容量公式 |
| "达到容量需要 0 误码" | 需要无限长码长 + 最优解码，实际系统只能逼近 |
