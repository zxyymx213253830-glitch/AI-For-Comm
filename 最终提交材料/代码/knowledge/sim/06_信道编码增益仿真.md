# 06 信道编码增益仿真（卷积码与维特比译码）

## 用途
仿真卷积码编码前后的误码率曲线，量化编码增益（典型 2~6dB），验证信道编码定理"编码可逼近信道容量"的结论。

## 核心原理
- (2,1,7) 卷积码：码率 1/2，约束长度 7，生成多项式八进制 171/133（经典 Voyager 码）
- 维特比译码在格状图上找最大似然路径，复杂度随约束长度指数增长
- 编码后误码率比较必须在**相同 Eb/N0** 下进行（编码使符号能量减半，需补偿）
- 软判决译码比硬判决额外获得约 2dB 增益

## 标准代码模板（基于 numpy 自实现，不依赖通信工具箱）

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.special import erfc

# ── (2,1,3) 简化卷积码：生成多项式 g1=111, g2=101（教学用，码率1/2）──
G1, G2 = 0b111, 0b101

def conv_encode(bits):
    state, out = 0, []
    for b in np.append(bits, [0, 0]):           # 尾部清零
        reg = (state << 1) | b
        out += [bin(reg & G1).count('1') % 2,
                bin(reg & G2).count('1') % 2]
        state = reg & 0b11
    return np.array(out)

def viterbi_hard(rx_bits, n_info):
    # 硬判决维特比：返回译码比特序列（简化实现）
    INF = 1e9
    path_metrics = {0: 0.0}; paths = {0: []}
    for i in range(0, len(rx_bits), 2):
        pair = rx_bits[i:i+2]
        new_m, new_p = {}, {}
        for s, m in path_metrics.items():
            for b in (0, 1):
                reg = (s << 1) | b
                enc = [bin(reg & G1).count('1') % 2,
                       bin(reg & G2).count('1') % 2]
                d = sum(e != r for e, r in zip(enc, pair))
                ns = reg & 0b11
                if ns not in new_m or m + d < new_m[ns]:
                    new_m[ns] = m + d
                    new_p[ns] = paths[s] + [b]
        path_metrics, paths = new_m, new_p
    best = min(path_metrics, key=path_metrics.get)
    return np.array(paths[best][:n_info])

rng = np.random.default_rng(4)
def coded_ber(ebn0_db, n_info=200000):
    ber = []
    for ebn0 in ebn0_db:
        snr = 10 ** (ebn0 / 10)
        sigma = np.sqrt(1 / (2 * 0.5 * snr))    # 码率1/2 → 符号能量减半
        bits = rng.integers(0, 2, n_info)
        tx = 2 * conv_encode(bits) - 1
        rx_hard = ((tx + sigma * rng.standard_normal(len(tx))) > 0).astype(int)
        dec = viterbi_hard(rx_hard, n_info)
        ber.append(np.sum(dec != bits) / n_info)
    return np.array(ber)

ebn0_db = np.arange(0, 9)
ber_coded = coded_ber(ebn0_db)
ber_uncoded = 0.5 * erfc(np.sqrt(10 ** (ebn0_db / 10)))

plt.semilogy(ebn0_db, ber_uncoded, 'k--', label='未编码·理论')
plt.semilogy(ebn0_db, ber_coded,   'rs-', label='(2,1,3)卷积码·硬判决')
plt.xlabel('Eb/N0 (dB)'); plt.ylabel('误码率 BER')
plt.title('卷积码编码增益'); plt.legend(); plt.grid(True, which='both')
plt.savefig('ber_coding_gain.png', dpi=150)
```

## 预期结果与校验点
1. BER=1e-5 附近，该简化卷积码相对未编码约有 2.5~3dB 编码增益（硬判决）
2. 门限效应：Eb/N0 低于约 4~5dB 时编码曲线高于未编码（如 3dB 处编码 3.1e-2 vs 未编码 2.3e-2），超过约 5dB 后反超——曲线必有一次交叉
3. 若编码曲线整体劣于未编码，先查 Eb/N0 是否按信息比特能量定义（别忘了除码率）

## 常见错误
- 比较时忘记码率补偿：编码符号能量 = 信息比特能量 × 码率
- 维特比尾部未清零导致末尾比特误码率虚高
