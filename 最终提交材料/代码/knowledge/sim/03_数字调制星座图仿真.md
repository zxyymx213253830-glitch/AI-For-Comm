# 03 数字调制星座图与噪声影响仿真

## 用途
绘制 QPSK、16QAM 的发射星座图与加噪后的接收星座图，直观展示信噪比对判决的影响。适合论文插图和演示。

## 核心原理
- QPSK：4 个星座点位于单位圆 45°、135°、225°、315°，每符号 2 比特
- 16QAM：4×4 矩形网格，需做能量归一化（除以 √10）使平均符号能量为 1
- 加噪后星座点呈高斯云扩散，云团半径 ≈ 噪声标准差；云团交叠即误码

## 标准代码模板

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(1)

# ── 16QAM 星座生成（格雷映射简化版）──
I = np.array([-3, -1, 1, 3]); Q = np.array([-3, -1, 1, 3])
constellation = (np.repeat(I, 4) + 1j * np.tile(Q, 4)) / np.sqrt(10)  # 能量归一化

snr_db_list = [5, 15]
fig, axes = plt.subplots(1, 3, figsize=(13, 4))

axes[0].scatter(constellation.real, constellation.imag, s=60, c='red')
axes[0].set_title('发射星座图 (16QAM)')

for ax, snr_db in zip(axes[1:], snr_db_list):
    n_sym = 2000
    tx = constellation[rng.integers(0, 16, n_sym)]
    noise_pwr = 1 / (10 ** (snr_db / 10))
    rx = tx + np.sqrt(noise_pwr / 2) * (rng.standard_normal(n_sym)
         + 1j * rng.standard_normal(n_sym))
    ax.scatter(rx.real, rx.imag, s=4, alpha=0.4)
    ax.set_title(f'接收星座图 (SNR={snr_db}dB)')

for ax in axes:
    ax.set_xlim(-2, 2); ax.set_ylim(-2, 2)
    ax.grid(True); ax.set_aspect('equal')
plt.tight_layout()
plt.savefig('constellation_16qam.png', dpi=150)
```

## 预期结果与校验点
1. SNR=5dB 时云团明显交叠（对应误码率较高），SNR=15dB 时 16 个云团清晰可分
2. 能量归一化后星座点平均功率应为 1（可用 np.mean(np.abs(c)**2) 验证 ≈ 1.0）
3. 格雷映射下相邻星座点只差 1 比特，误码率约为误符号率的 1/log2(M)

## 常见错误
- 16QAM 忘记能量归一化，导致与理论误码率公式对不上（差约 5dB）
- 复噪声的实部虚部各取噪声功率的一半
