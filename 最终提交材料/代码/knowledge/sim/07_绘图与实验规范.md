# 07 绘图与实验报告规范

## 用途
统一 sim_agent 产出的仿真图像风格，达到论文插图级别；规范实验结论的表述方式。

## 绘图硬性规范
1. **中文显示**：必须设置中文字体，避免标题乱码
   ```python
   plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei']
   plt.rcParams['axes.unicode_minus'] = False
   ```
2. **分辨率**：保存图像统一 `dpi=150` 以上，论文投稿用 300
3. **坐标轴**：误码率曲线必须用半对数坐标（`plt.semilogy`）；横轴标注单位（dB）
4. **图例与标题**：每张图必须有图例区分"理论/仿真"曲线，标题写明实验内容
5. **配色**：理论曲线用实线，仿真结果用带标记的散点，便于区分
6. **文件命名**：输出图片用英文小写下划线命名（如 ber_awgn.png），避免中文路径问题

## 仿真结论表述规范
每次仿真输出必须包含四部分：
1. **实验设置**：调制方式、信道模型、仿真参数（比特数、随机种子）
2. **关键数值**：至少给出 2~3 个特征点的数值结果（如"BER=1e-5 需 Eb/N0=9.6dB"）
3. **理论对照**：与理论值的偏差，偏差超过 10% 必须说明原因
4. **图表**：保存为 PNG 并说明文件名与图中内容

## 可复现性要求
- 所有随机过程必须固定随机种子（rng = np.random.default_rng(seed)），保证结果可复现
- 蒙特卡洛仿真必须报告仿真样本量；误码数为 0 时不能写"误码率为 0"，应写"低于 3/样本数"
- 仿真耗时应控制在合理范围：单次实验建议 2 分钟内，超过则降低样本量并声明置信度下降

## 与其他 Agent 的接口约定
- 收到 math_agent 的公式结论时：仿真必须覆盖公式中的关键参数点，并在结论中显式对照（"理论值 X，仿真值 Y，偏差 Z%"）
- 收到 verify_agent 的质疑时：重新运行时保持种子不变，仅修改被指出的问题
- 图像路径、代码全文、数值结论三者必须同时交付，缺一不可
