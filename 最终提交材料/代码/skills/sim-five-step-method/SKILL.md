# 仿真五步法（真执行闭环）

## 何时使用

用户/上游任务要求给出通信系统数值仿真结果（误码率曲线、信道容量、中断概率、分集增益等），且结论需要与理论公式对照验证时。

## 五步流程（必做，缺一不可）

1. **【方案】** 一行写明仿真场景与参数：调制方式、SNR/Eb-N0 范围与步进、蒙特卡洛符号数、随机种子
2. **【代码】** 输出完整可运行的 Python 代码（numpy 实现），关键参数注释含义；出图用 `plt.savefig('xxx.png')`，禁止 `plt.show()`
3. **【真执行】** 代码必须真实运行（本地执行环境/工具），记录退出码与标准输出——**禁止交"没跑过的代码"**
4. **【理论对比】** 仿真结果与理论公式同图对比（如 BPSK 理论 Pe = Q(√(2·Eb/N0))），偏差 >10% 必须分析原因
5. **【出图】** 输出 semilogy 曲线 PNG，图例标注"仿真"与"理论"两条曲线

## 输出格式（按序）

- ```python 代码块（优先带围栏；若通道禁围栏，从 import 行起手、每个章节用【】标记分隔）
- 【运行结果】关键 SNR 点的实测值 vs 理论值对照表
- 【对比结论】一句话偏差分析（是否吻合、原因）
- 【图】PNG 图片路径

## 硬约束

- 目标 BER 低于 1e-3 时蒙特卡洛符号数至少 1e5，并注明随机种子保证可复现
- 理论公式必须注明出处（如 Proakis 2001, Eq. (5.2-42)）
- SNR 一律用 dB，dB↔线性换算显式给出（10^(dB/10)），Eb/N0 ↔ Es/N0 按调制阶数换算
- 编造运行结果一律视为不合格；执行失败时修正代码重新执行，不得虚构成功

## 协作

仿真完成后把代码+运行结果送校验环节做四项清单检查（量纲/单调性/特殊值代入/文献对照）；收到【不通过】按反馈修正代码后**重新执行**再提交新结果。

## 本地执行环境说明（给编排端）

平台智能体无文件系统：代码提取、真实执行、图表回收由本地流水线完成（tools/sim_tools：临时目录隔离、无窗口绘图后端、中文字体预置、PNG 自动嵌入报告），执行结果回灌智能体完成第 4~5 步。
