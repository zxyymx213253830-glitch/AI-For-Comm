# 目录结构说明（提交版）

> AI for Comm —— 通信领域多智能体科研协作系统。本地编排 + OpenTrek 平台智能体混合架构。
> 各目录内均备有 README.md 详述用途，本文件为总览地图。

## 一、核心代码（运行时必需）

| 目录/文件 | 分类 | 用途 |
|---|---|---|
| `core/` | 核心架构 | 智能体通用节点、六步科研流水线、协作编排、消息总线、工具回环驱动、报告渲染、配置管理 |
| `agents/` | 智能体角色层 | 7 个智能体各自的本地子类（数学/协议/硬件/仿真/校验/文献/报告） |
| `tools/` | 本地工具集 | SymPy 计算、通信算法库、代码沙箱执行、Verilog 仿真、文献检索、本地资料检索、工具注册表 |
| `prompts/` | AI 提示词 | 各智能体角色手册与硬约束（与平台在线提示词同源） |
| `web/` | Web 前端与应用 | Flask 服务：对话、科研流水线、报告库、监控、设置共 6 个中文页面 |
| `knowledge/` | 本地知识库源文档 | 信息论 9 专题 + 仿真模板 6 类 + 权威文献（平台知识库建库底稿） |
| `skills/` | 平台技能源文件 | 3 个技能包（仿真五步法 / 科研汇报统稿 / 高审美排版规范），已上架平台 Skills Hub |
| `config.json` | 运行配置 | 平台地址密钥 + 7 个智能体的编号/版本/知识库挂载（设置页可视化编辑） |
| `main.py` | 命令行入口 | 不经 Web 界面直接跑一次双智能体协作研究 |
| `build_kb_json.py` | 工具脚本 | 把 knowledge/sim 打包为平台知识库导入 JSON（须留在根目录，按自身位置解析路径） |

## 二、质量保障

| 目录 | 用途 |
|---|---|
| `evals/` | 38 题能力评测集 + 评测结果（题库、说明、results 产物） |
| `tests/` | 各级测试脚本、评测执行器、一键测试批处理 |
| `logs/` | 结构化运行日志（排查平台交互的第一手证据） |

## 三、产物与文档

| 目录 | 用途 |
|---|---|
| `outputs/` | 运行产物：research_*.html 研究报告（报告库数据源）、sim/ 仿真图表、存档/ 历史杂项 |
| `docs/` | 项目文档：方案书、架构图、结课汇报书、排查记录；子目录含平台参考资料（官方 PDF）、设计稿与Logo、验证记录图片 |
| `archive/` | 归档区：队友交付包原件、建设期旧版程序（不参与运行，仅溯源） |

## 四、部署与环境

| 文件/目录 | 用途 |
|---|---|
| `Dockerfile` / `docker-compose.yml` / `.dockerignore` | 容器化部署定义 |
| `requirements.txt` | Python 依赖清单 |
| `.venv/` | 本机 Python 虚拟环境（不提交） |
| `.qoder/` `.workbuddy/` | 开发工具配置与工作记忆（不提交） |

## 五、启动方式

```
方式一（Web）：python web/app.py        →  http://localhost:7860
方式二（命令行）：python main.py          →  控制台看协作过程，报告落 outputs/
方式三（容器）：docker compose up
```
