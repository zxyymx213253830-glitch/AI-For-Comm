# 02 香农信道容量仿真

## 用途
绘制 AWGN 信道容量随信噪比、带宽变化的曲线，验证香农公式 C = B·log2(1+S/N)，支撑 math_agent 的理论推导结论。

## 核心原理
- 香农公式：C = B·log2(1 + SNR)，单位 bit/s
- 归一化容量（谱效率）：C/B = log2(1+SNR)，单位 bit/s/Hz，与带宽无关
- 带宽趋于无穷时的极限：C∞ = (S/N0)·log2(e) ≈ 1.44·S/N0

## 标准代码模板

```python
import numpy as np
import matplotlib.pyplot as plt

snr_db = np.arange(-10, 31)
snr_lin = 10 ** (snr_db / 10)

# 谱效率曲线（与带宽无关）
spectral_eff = np.log2(1 + snr_lin)

# 固定带宽 B=20MHz 的容量曲线
B = 20e6
capacity_mbps = B * np.log2(1 + snr_lin) / 1e6

fig, axes = plt.subplots(1, 2, figsize=(11, 4))
axes[0].plot(snr_db, spectral_eff, 'b-')
axes[0].set_xlabel('SNR (dB)'); axes[0].set_ylabel('谱效率 (bit/s/Hz)')
axes[0].set_title('归一化信道容量'); axes[0].grid(True)

axes[1].plot(snr_db, capacity_mbps, 'r-')
axes[1].set_xlabel('SNR (dB)'); axes[1].set_ylabel('容量 (Mbps)')
axes[1].set_title('B=20MHz 时的信道容量'); axes[1].grid(True)

plt.tight_layout()
plt.savefig('shannon_capacity.png', dpi=150)

# 数值校验：B=20MHz、SNR=30dB → C ≈ 199.5 Mbps
print(f"校验: SNR=30dB 时 C = {20*np.log2(1+1000):.1f} Mbps")
```

## 预期结果与校验点
1. SNR=30dB、B=20MHz 时容量约 199.5 Mbps（与 math_agent 经典推导题一致，可用于交叉验证）
2. SNR=0dB 时谱效率恰好为 1 bit/s/Hz
3. 高信噪比区曲线近似线性：每增加 3dB，谱效率约增加 1 bit/s/Hz

## 常见错误
- log 与 log2 混用（容量必须用 log2）
- dB 值未换算成线性值就直接代入公式
