# 04 瑞利衰落信道误码率仿真

## 用途
仿真 BPSK 在平坦瑞利衰落信道下的误码率，与 AWGN 结果对比，直观展示衰落带来的性能损失（高信噪比区误码率下降变缓，出现"地板效应"）。

## 核心原理
- 瑞利衰落系数 h = (h_I + j·h_Q)/√2，实虚部均为零均值高斯，|h| 服从瑞利分布
- 接收信号 r = h·x + n，相干检测需信道估计：判决用 r/h
- BPSK 瑞利衰落理论误码率（有闭式解）：BER = 0.5·(1 − √(γb/(1+γb)))，γb = Eb/N0（线性值）
- 高信噪比近似：BER ≈ 1/(4·γb)，即以每十倍频程 -1 的斜率下降，远慢于 AWGN 的指数下降

## 标准代码模板

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.special import erfc

def bpsk_rayleigh_ber(ebn0_db, num_bits=500000, seed=2):
    rng = np.random.default_rng(seed)
    ber = []
    for ebn0 in ebn0_db:
        snr_lin = 10 ** (ebn0 / 10)
        sigma = np.sqrt(1 / (2 * snr_lin))
        bits = rng.integers(0, 2, num_bits)
        x = 2.0 * bits - 1
        h = (rng.standard_normal(num_bits)
             + 1j * rng.standard_normal(num_bits)) / np.sqrt(2)
        n = sigma * (rng.standard_normal(num_bits)
             + 1j * rng.standard_normal(num_bits))
        rx = h * x + n
        detect = np.real(rx / h)          # 相干检测（完美信道估计）
        err = np.sum((detect > 0) != (x > 0))
        ber.append(err / num_bits)
    return np.array(ber)

ebn0_db = np.arange(0, 25, 2)
ber_sim = bpsk_rayleigh_ber(ebn0_db)
gb = 10 ** (ebn0_db / 10)
ber_theory = 0.5 * (1 - np.sqrt(gb / (1 + gb)))
ber_awgn = 0.5 * erfc(np.sqrt(gb))        # AWGN 对照

plt.semilogy(ebn0_db, ber_theory, 'b-', label='瑞利衰落·理论')
plt.semilogy(ebn0_db, ber_sim,    'bo', label='瑞利衰落·仿真')
plt.semilogy(ebn0_db, ber_awgn,   'g--', label='AWGN·理论(对照)')
plt.xlabel('Eb/N0 (dB)'); plt.ylabel('误码率 BER')
plt.title('BPSK：瑞利衰落 vs AWGN')
plt.legend(); plt.grid(True, which='both')
plt.savefig('ber_rayleigh.png', dpi=150)
```

## 预期结果与校验点
1. Eb/N0=20dB 时：瑞利衰落误码率约 2.5e-3，而 AWGN 已低至 1e-45 量级（实际为零）——这就是分集/编码的必要性来源
2. 仿真与理论曲线应重合；不重合先检查 h 的功率归一化（E[|h|²]=1）
3. 曲线高信噪比段呈直线（对数坐标），斜率对应无分集阶数 1

## 常见错误
- 衰落系数每符号更新还是每比特更新的语义混淆（本模板为每比特独立衰落，即交织充分的情形）
- 检测时忘记除以 h 直接用实部判决
