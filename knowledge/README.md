# knowledge/ —— 本地知识库源文档

供 `tools/protocol_tools.py` 离线检索，也是平台知识库的建库底稿：

- `math/` —— 信息论与通信数学 9 大专题（香农容量、AWGN、熵与互信息、信道编码、调制、MIMO 等），
  `权威文献/` 存有 Shannon 1948 原文与西电讲义（md + pdf）
- `sim/` —— 通信仿真模板 6 类 + 绘图规范（误码率蒙特卡洛、香农容量、星座图、瑞利衰落、MIMO 容量、编码增益），
  代码模板均经本地数值验证；`build_kb_json.py` 可将其打包为平台知识库导入格式

平台对应库：信息论数学标准库、通信仿真标准库（内容同源）。
