# 数字调制解调

## 别名
Digital modulation、调制、Modulation、QAM、QPSK、BPSK、M-PSK、M-QAM、OFDM、星座图

---

## 一、调制的基本问题

```
数字调制的本质：

  比特序列 → [星座映射] → 复符号序列 → [脉冲成型] → 模拟波形

  b₁b₂...bₖ  →  s ∈ C (星座点)  →  s·g(t)·e^(j2πf_c t)

每个符号携带 log₂(M) 比特，M 为星座点数量
```

### 1.1 三个核心设计权衡

```
M ↑ → 频谱效率 ↑  (更多比特/符号)
M ↑ → 功率效率 ↓  (星座点更密集，对噪声敏感)
M ↑ → 实现复杂度 ↑  (PA 线性度需求高)
```

## 二、常见调制方案

### 2.1 BPSK（二进制相移键控）

```
星座图：          Q
                  |
         '1'  ●───+───●  '0'
                  |      I

比特映射：0 → +√(Eb), 1 → -√(Eb)

BER (AWGN):
  P_b = Q(√(2·Eb/N₀))

频谱效率：1 bps/Hz (未编码)
功率效率：Eb/N₀=9.6 dB @ BER=10⁻⁵
```

### 2.2 QPSK（四进制相移键控）

```
星座图：          Q
                  |
                01│00
             ●────+────●
                  |
                11│10
             ●────+────●
                  I

比特映射：用 Gray 码（相邻星座点仅差 1 bit）

BER (AWGN):
  P_b ≈ Q(√(2·Eb/N₀))  （与 BPSK 相同！）
  
  QPSK = 2 路正交 BPSK → 每路独立，BER 相同

频谱效率：2 bps/Hz
```

### 2.3 M-PSK（M 进制相移键控）

```
星座图 (M=8, 8-PSK):

        Q
     ●     ●
   ●         ●
   │         │
 ──+─────────+── I
   │         │
   ●         ●
     ●     ●

BER 近似：
  P_b ≈ (2/log₂M)·Q(sin(π/M)·√(2·Eb·log₂M/N₀))

适用：M ≤ 8，高 M 时不如 QAM
```

### 2.4 M-QAM（正交幅度调制）

```
16-QAM 星座图 (4×4):

  Q ↑
    │ 0010  0110  1110  1010
    │
    │ 0011  0111  1111  1011
    │
────┼──────────────────────→ I
    │ 0001  0101  1101  1001
    │
    │ 0000  0100  1100  1000

BER 近似 (Gray 编码)：
  P_b ≈ (4/log₂M)·(1-1/√M)·Q(√(3·log₂M·Eb/((M-1)·N₀)))

适用：M ≥ 16
```

### 2.5 调制方案全对比

| 调制 | bit/符号 | η (未编码) | Eb/N₀ @ BER=10⁻⁵ | 峰均比 PAPR |
|------|---------|-----------|-------------------|-----------|
| BPSK | 1 | 1 | 9.6 dB | 0 dB |
| QPSK | 2 | 2 | 9.6 dB | 0 dB |
| 8-PSK | 3 | 3 | 14.0 dB | 0 dB |
| 16-QAM | 4 | 4 | 13.5 dB | 2.6 dB |
| 64-QAM | 6 | 6 | 17.6 dB | 3.7 dB |
| 256-QAM | 8 | 8 | 22.0 dB | 4.2 dB |
| 1024-QAM | 10 | 10 | 26.5 dB | ~4.5 dB |

## 三、Gray 编码

### 3.1 原理

```
Gray 码规则：相邻星座点的二进制标记仅差 1 bit

好处：当符号检测错误跳到相邻星座点时（最常见错误），
      仅产生 1 bit 错误而不是 log₂(M) bit

例如 16-QAM 未用 Gray 编码 vs Gray 编码：
  → 相邻点误判：未 Gray 可能 3-4 bit 错，Gray 只有 1 bit 错
  → BER 改善约 2-3 dB
```

### 3.2 构造方法

```
n-bit Gray 码的递归构造：

  G₁ = [0, 1]
  Gₖ₊₁ = [0·Gₖ, 1·Gₖ_reversed]
        （前半前面加 0，后半倒序前面加 1）

例如 3-bit Gray 码：
  000, 001, 011, 010, 110, 111, 101, 100
```

## 四、最优检测

### 4.1 匹配滤波器

```
接收机前端最优滤波器：滤波器冲激响应 = 发送脉冲的共轭反转

  h_mf(t) = g*(-t)

  → 最大化 t=0 时刻的采样 SNR
  → 等效于在噪声中做"相关"
```

### 4.2 最大似然检测 (ML)

```
接收信号 r = s + n, n ~ CN(0, N₀)

最大似然准则：
  ŝ = argmin_s |r - s|²

  → 选星座图上距 r 最近的符号
  → AWGN 下的最优检测器
  → 决策边界 = 相邻星座点的垂直平分线
```

### 4.3 对数似然比 (LLR) 计算

```
对于比特 bₖ, LLR 定义为：

  LLR(bₖ) = log( P(bₖ=0|r) / P(bₖ=1|r) )

在 AWGN 下：
  LLR(bₖ) = log( Σ_{s: bₖ=0} exp(-|r-s|²/N₀) /
                 Σ_{s: bₖ=1} exp(-|r-s|²/N₀) )

近似 (Max-Log-MAP)：
  LLR(bₖ) ≈ (1/N₀)·[ min_{s: bₖ=1} |r-s|² - min_{s: bₖ=0} |r-s|² ]

→ LLR 送入软输入解码器 (LDPC/Polar/Turbo) 做迭代解码
```

## 五、OFDM 原理与实现

### 5.1 系统模型

```
                   ┌─ 子载波 1: X₁·e^(j2πf₁t)
                   │
  串行 ──[S/P]──→ ─┼─ 子载波 2: X₂·e^(j2πf₂t)
  比特    分配     │        ...
                   └─ 子载波 N: X_N·e^(j2πf_Nt)

          ∑ X_k·e^(j2πf_k t)  ──→ 信道

收端：每个子载波上的接收符号 Y_k = H_k·X_k + Z_k
```

### 5.2 正交性条件

```
子载波间距 Δf = 1/Tₛ（Tₛ 为 OFDM 符号周期）

在此条件下，任意两个子载波内积为零：
  ∫_0^Tₛ e^(j2πf_m t)·e^(-j2πf_n t) dt = 0  (m≠n)

→ 子载波互不干扰
→ 每路子载波是独立的平坦衰落信道
→ 每路可用简单的一抽头均衡
```

### 5.3 循环前缀 (CP)

```
在 OFDM 符号前附加 CP（复制符号末尾的一段）：

  [CP (N_cp 样点)] [OFDM 数据 (N 样点)]

作用：
  1. 消除符号间干扰 (ISI)：CP 长度 > 最大多径时延
  2. 将线性卷积变为循环卷积：H·X → H_circular·X
  3. 频域等效：Y_k = H_k·X_k + Z_k（简单！）

代价：频谱效率降低 N/(N+N_cp)
```

### 5.4 FFT 实现

```
OFDM 调制 ✓ 可以用 IFFT 高效实现：

  时域信号 x[n] = (1/N)·Σ X[k]·e^(j2πkn/N)   ← IFFT
                  k=0

复杂度：O(N·log N) 而不是 O(N²)

5G NR 的典型参数：
  子载波间距: 15/30/60/120 kHz
  最大 FFT 大小: 4096
  最大 RBs (Resource Blocks): 275 (≈ 100 MHz @ 30 kHz SCS)
```

## 六、PAPR 问题

### 6.1 定义

```
PAPR = max_t |x(t)|² / E[|x(t)|²]

OFDM 的高 PAPR：
  当多个子载波同相叠加时，瞬时功率远大于平均功率
  → 要求 PA 有极大线性范围（否则信号被限幅，产生带外泄漏）
  → PA 效率降低（需要更大回退 power back-off）
```

### 6.2 降低 PAPR 的方法

| 方法 | 原理 | PAPR 降低 | 代价 |
|------|------|----------|------|
| **DFT-s-OFDM** | 先 DFT 再 OFDM → 单载波特性 | 显著 | 灵活性降低 |
| **限幅 + 滤波** | 削去峰值 | 中等 | 带内失真 |
| **SLM/PTS** | 多候选信号挑最小 PAPR | 中等 | SI 开销 |
| **Tone Reservation** | 预留子载波做峰值消除 | 小 | 速率损失 |

### 6.3 5G NR 的选择

```
下行 (gNB → UE): CP-OFDM
  → PA 效率不是瓶颈（基站供电充足）
  → 灵活的资源调度 > PAPR 问题

上行 (UE → gNB): DFT-s-OFDM 或 CP-OFDM
  → 电池供电的 UE 需要低 PAPR
  → DFT-s-OFDM 作为默认，高 SNR 时可切 CP-OFDM 提高频谱效率
```

## 七、调制与编码的联合：BICM

### 7.1 比特交织编码调制 (BICM)

```
比特序列 → [编码] → [比特交织] → [星座映射] → 信道

解调：每个比特独立计算 LLR → [解交织] → [解码]

优势：
  - 调制和编码可以独立设计
  - 交织打破突发错误
  - Gray 映射 + 编码 → 接近容量
```

### 7.2 容量对比

| 方案 | 差距 vs 香农限 (AWGN, 16-QAM) |
|------|---------------------------|
| BICM + LDPC (5G NR) | ~0.5-1.0 dB |
| TCM (网格编码调制) | ~1.5-2.0 dB |
| 未编码 16-QAM | ~5-7 dB |

## 八、例题

### 例题 1（符号错误率转 BER）

16-QAM，Gray 编码，接收 SNR=15 dB。求近似 BER。

```
SNR_linear = 10^(15/10) = 31.62

每符号 SNR (Es/N₀) = Eb/N₀ × log₂M = SNR × (B/Rs)

对于未编码 16-QAM：
  Es/N₀ = SNR = 31.62 → 15 dB
  Eb/N₀ = Es/N₀ / 4 = 31.62/4 = 7.9 → 8.98 dB

BER 公式：
  Q 参数 = √(3·log₂M·Eb/((M-1)·N₀)) = √(3·4·7.9/15) = √(94.8/15) = √6.32 ≈ 2.51

P_b ≈ 4·(1-1/4)/4 · Q(2.51) = (3/4)·Q(2.51)

查 Q 表：Q(2.51) ≈ 6.0×10⁻³
P_b ≈ 0.75 × 6.0×10⁻³ = 4.5×10⁻³

→ BER ≈ 0.45%
```

### 例题 2（调制选择）

系统要求 BER ≤ 10⁻⁵，信道 SNR=20 dB。可选哪些调制方案？

```
SNR_linear = 100 → 20 dB

参考调制表：
  BPSK:    9.6 dB ✓
  QPSK:    9.6 dB ✓
  8-PSK:  14.0 dB ✓
  16-QAM: 13.5 dB ✓
  64-QAM: 17.6 dB ✓
  256-QAM: 22.0 dB ✗

→ 最高可选 64-QAM（包含编码余量后可能需退一档）
```

## 九、5G NR 调制方案速查

| 调制 | 使用场景 | 备注 |
|------|---------|------|
| **QPSK** | 小区边缘、控制信道、URLLC | 最低 SNR 需求 |
| **16-QAM** | 中覆盖数据信道 | 平衡效率与鲁棒性 |
| **64-QAM** | 良好覆盖数据信道 | 需要高精度 RF |
| **256-QAM** | 极好覆盖 / 小小区 | 5G 新增（4G 最高 64-QAM） |
| **π/2-BPSK** | DFT-s-OFDM 上行 | 进一步降低 PAPR |
| **DBPSK** | 不需要信道估计的场景 | 差分检测 |
