# 熵与互信息

## 别名
熵、信息熵、Entropy、香农熵、Shannon entropy、互信息、Mutual Information、KL 散度、相对熵

---

## 一、信息熵 (Entropy)

### 1.1 定义

离散随机变量 X ~ p(x) 的熵：

```
H(X) = -Σ p(x) · log₂ p(x) = E[-log₂ p(X)]
      x

约定：0·log₂(0) = 0 （lim_{p→0+} p·log p = 0）
```

### 1.2 物理含义

| 视角 | 解释 |
|------|------|
| **不确定性** | X 取值的不确定程度，H 越大越不确定 |
| **信息量** | 观测到 X 后平均获得的信息量（惊喜程度） |
| **压缩极限** | 无损压缩 X 所需的最少比特数/符号 |
| **复杂度** | 用比特描述 X 所需的最短描述长度 |

### 1.3 性质

```
1. H(X) ≥ 0                              非负性
2. H(X) ≤ log₂(N)                        最大熵（等概时取等号）
3. H(X) = 0 ⟺ X 是确定性变量（∃i: pᵢ=1）  确定性零熵
4. H(f(X)) ≤ H(X)                         函数不增加熵（等号当 f 可逆）
```

### 1.4 二元熵函数

二元随机变量（概率 p 和 1-p）的熵：

```
H₂(p) = -p·log₂ p - (1-p)·log₂(1-p)

       ↑
  1.0 ┤     ╱‾‾‾‾╲
      ┤    ╱      ╲
  0.5 ┤         ●     ← p=0.5 时最大，H=1 bit
      ┤  ╱          ╲
  0.0 ┤●────────────────●
      0               1  p
```

**例题**：p=0.3 时，H₂(0.3) = ?

```
H₂(0.3) = -0.3·log₂(0.3) - 0.7·log₂(0.7)
        = -0.3·(-1.737) - 0.7·(-0.515)
        = 0.521 + 0.360
        = 0.881 bit
```

## 二、联合熵与条件熵

### 2.1 定义

```
联合熵: H(X,Y) = -ΣΣ p(x,y)·log₂ p(x,y)
条件熵: H(Y|X) = -Σ p(x)·H(Y|X=x)
                = -ΣΣ p(x,y)·log₂ p(y|x)
```

### 2.2 链式法则（核心工具）

```
H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)

推广到 n 个变量：
H(X₁,...,Xₙ) = Σ H(Xᵢ | X₁,...,Xᵢ₋₁)
              i=1
```

### 2.3 条件熵的直观含义

```
H(Y|X) = "知道 X 后，Y 还剩多少不确定性"

若 X 完全确定 Y：H(Y|X) = 0
若 X 与 Y 独立：H(Y|X) = H(Y)
一般情况下：      0 ≤ H(Y|X) ≤ H(Y)     ——"条件不增加熵"
```

### 2.4 例题

**题目**：X ∈ {A,B} 等概，给定 X 后 Y 的条件分布为：

```
X=A: Y=0 概率 0.9, Y=1 概率 0.1
X=B: Y=0 概率 0.2, Y=1 概率 0.8
```

求 H(X), H(Y|X), H(X,Y)。

**解**：
```
H(X) = H₂(0.5) = 1 bit

H(Y|X=A) = H₂(0.1) = -0.1·log₂0.1 - 0.9·log₂0.9 ≈ 0.469 bit
H(Y|X=B) = H₂(0.2) = -0.2·log₂0.2 - 0.8·log₂0.8 ≈ 0.722 bit

H(Y|X) = 0.5·0.469 + 0.5·0.722 = 0.596 bit

H(X,Y) = H(X) + H(Y|X) = 1 + 0.596 = 1.596 bit
```

## 三、互信息 (Mutual Information)

### 3.1 定义

```
I(X;Y) = H(X) - H(X|Y)         ← 知道 Y 后，X 的不确定性减少多少
       = H(Y) - H(Y|X)         ← 对称定义
       = D_KL( p(x,y) || p(x)·p(y) )  ← KL 散度视角
       = ΣΣ p(x,y)·log₂( p(x,y) / (p(x)·p(y)) )
```

### 3.2 Venn 图表示

```
     H(X)              H(Y)
 ┌──────────┐      ┌──────────┐
 │          │      │          │
 │  H(X|Y)  │I(X;Y)│  H(Y|X)  │
 │          │      │          │
 └──────────┘      └──────────┘
 └──────── H(X,Y) ────────────┘
```

### 3.3 性质

```
1. I(X;Y) ≥ 0                        非负性（等号当 X⊥Y）
2. I(X;Y) = I(Y;X)                   对称性
3. I(X;Y) ≤ min(H(X), H(Y))         互信息不超过任一边际熵
4. I(X;Y|Z) ≥ 0                      条件互信息也非负
5. I(X;Y,Z) = I(X;Y) + I(X;Z|Y)     链式法则
```

### 3.4 信道容量与互信息的关系

```
C = max I(X;Y)
    p(x)

→ 让输入分布 p(x) 变化，互信息的最大值 = 信道容量
→ 达到容量的那个 p(x) 叫最优输入分布
→ AWGN 信道的最优分布是高斯分布
```

## 四、KL 散度（Kullback-Leibler Divergence）

### 4.1 定义

```
D_KL(P || Q) = Σ P(x)·log₂(P(x)/Q(x))
              x

P: 真实分布
Q: 模型/近似分布
```

### 4.2 性质

```
1. D_KL(P||Q) ≥ 0                    Gibbs 不等式（等号当 P=Q）
2. D_KL(P||Q) ≠ D_KL(Q||P)          不对称！
3. D_KL(P||Q) 不是真正的"距离"      不满足三角不等式

4. D_KL(P||Q) 对 (P,Q) 联合凸        对数和不等式的直接推论
```

### 4.3 物理含义

```
D_KL(P||Q) = "用分布 Q 来编码来自分布 P 的数据
             比用分布 P 编码要多浪费多少比特"

→ 如果 Q=P，不浪费
→ 如果 Q≠P，浪费 D_KL(P||Q) bit/符号
→ "模型错误的代价"的精确度量
```

### 4.4 例题

抛硬币，真实正面概率 0.7，你以为公平（以为概率 0.5）。KL 散度多大？

```
D_KL(P||Q) = 0.7·log₂(0.7/0.5) + 0.3·log₂(0.3/0.5)
           = 0.7·0.485 + 0.3·(-0.737)
           ≈ 0.118 bit

含义：每次抛硬币，你平均会多浪费约 0.118 bit
```

### 4.5 KL 散度与最大似然估计

最小化 D_KL(P_true || P_model) 等价于最大化似然：

```
argmin_θ D_KL(P_data || P_θ) = argmax_θ Σ log P_θ(x)

→ 最大似然 = 最小化 KL 散度（非参数意义下）
```

## 五、微分熵 (Differential Entropy)

### 5.1 定义

连续随机变量 X ~ f(x) 的微分熵：

```
h(X) = -∫ f(x)·log₂ f(x) dx
```

⚠️ **微分熵不是熵的直接推广**——它可以为负！因为它依赖于坐标系的选择。

### 5.2 常见分布的微分熵

| 分布 | 密度函数 | 微分熵 |
|------|---------|--------|
| **均匀 U[a,b]** | 1/(b-a) | log₂(b-a) |
| **高斯 N(μ,σ²)** | 实数 | (1/2)·log₂(2πeσ²) |
| **高斯 CN(μ,σ²)** | 复数 | log₂(πeσ²) |
| **指数 λ** | λe^(-λx) | log₂(e/λ) |
| **拉普拉斯** | (1/2b)·e^(-\x-μ\/b) | log₂(2be) |

### 5.3 最大熵分布

| 约束 | 最大熵分布 | 直觉 |
|------|----------|------|
| 有限区间 [a,b] | 均匀分布 | 无偏置 → 均匀 |
| 固定方差 | 高斯分布 | 高斯是最"散"的 |
| 固定均值（正值） | 指数分布 | 给定均值的最不确定正分布 |
| 无约束 | 不存在 | 始终可以更"散" |

### 5.4 微分熵下的互信息

```
I(X;Y) = h(X) - h(X|Y) = h(Y) - h(Y|X)
```

好消息：虽然单个微分熵可能为负或变化，**互信息在微分熵下依然非负且坐标不变**。

## 六、渐近均分性 (AEP) 与典型集

### 6.1 AEP 核心思想

```
n 个 i.i.d. 随机变量 Xⁿ = (X₁,...,Xₙ)，p(xⁿ) = Π p(xᵢ)

当 n → ∞：
  -(1/n)·log p(Xⁿ) → H(X)  (依概率)

这意味着绝大多数序列的概率近似为 2^(-nH)。
```

### 6.2 典型集

```
A_ε^(n) = { xⁿ: |-(1/n)·log p(xⁿ) - H| < ε }

典型集的三件套性质（对 n 足够大）：
  1. |A_ε^(n)| ≈ 2^(nH)     — 约 2^(nH) 个典型序列
  2. Pr(A_ε^(n)) ≈ 1         — 几乎必然落入典型集
  3. p(xⁿ) ≈ 2^(-nH)         — 典型序列几乎等概率
```

### 6.3 为什么 AEP 如此重要

```
AEP 是一切信息论定理证明的基石：

信源编码 → 只需编码典型集（2^(nH) 个元素 → nH bit 够）
信道编码 → 随机码字 + 典型集 → 证明 R<C 可达
率失真   → 典型集 + 量化 → 证明 R(D) 可达
```

## 七、常见分布下的信息量速查

| 场景 | 熵 H | 最大熵条件 |
|------|------|----------|
| 公平硬币 | 1 bit | 天然等概 |
| 公平六面骰子 | log₂6 ≈ 2.585 bit | 天然等概 |
| 英文 26 字母 (等概) | log₂26 ≈ 4.700 bit | 等概 |
| 英文文本 (真实分布) | ≈ 1.0-1.5 bit/字符 | — |
| 高斯分布 N(0,σ²) | (1/2)·log₂(2πeσ²) | 给定方差下最大熵 |
| BSC(p) 信道容量 | 1 - H₂(p) | 输入等概 |
| BEC(ε) 信道容量 | 1 - ε | 输入等概 |

## 八、例题综合

### 例题 1（信道容量的信息论推导）

BSC(0.1) 的信道容量。

```
BSC(ε): 输入 X∈{0,1}, 输出 Y∈{0,1}, Pr(Y≠X) = ε

I(X;Y) = H(Y) - H(Y|X) = H(Y) - H₂(ε)

由对称性，X 等概 ⇒ Y 也等概：
  H(Y) = 1
  I(X;Y) = 1 - H₂(0.1) = 1 - 0.469 = 0.531 bit/信道使用
  C = 0.531 bit
```

### 例题 2（条件不增熵的量化）

某信道的噪声 Z 与输入 X 独立，Y = X + Z。

```
H(Y|X) = H(Z)     （知道 X 后，Y 的不确定性 = Z 的不确定性）
H(Y) ≥ H(X)       （输出熵 ≥ 输入熵，当 Z 非零时严格大于）

I(X;Y) = H(Y) - H(Z) ≤ H(Y)

→ 互信息 ≤ 输出熵（合理——不能从输出获取超过输出本身的信息）
```
