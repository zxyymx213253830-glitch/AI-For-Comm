# AWGN 信道模型

## 别名
Additive White Gaussian Noise channel、加性高斯白噪声信道、高斯信道

---

## 一、基本定义

### 1.1 数学模型

AWGN 是最基本的通信信道模型：

```
基带等效模型:          y(t) = x(t) + n(t)

其中：
  x(t): 发送信号（复基带）
  n(t): 复加性高斯白噪声
        E[n(t)] = 0
        E[n(t)·n*(t+τ)] = N₀·δ(τ)  ← "白"的含义：各时刻独立
        n(t) ~ CN(0, N₀)            ← "高斯"的含义
```

### 1.2 为什么 AWGN 是"最基本"的信道

| 原因 | 说明 |
|------|------|
| **中心极限定理** | 众多独立噪声源叠加 → 高斯分布是自然的 |
| **最大熵分布** | 给定功率约束，高斯噪声是最恶劣的（最大化信道不确定性） |
| **数学易处理** | 高斯分布在线性变换下保持高斯性 |
| **最坏信道** | 在相同功率下，高斯噪声给出最小的信道容量 → 设计保守但安全 |

### 1.3 复基带表示

物理射频信号是实信号，但数学上用复基带更简洁：

```
RF 信号: s(t) = Re{ x(t)·e^(j2πf_c t) }

复基带信号 x(t) = I(t) + j·Q(t)
  I(t): 同相分量 (In-phase)
  Q(t): 正交分量 (Quadrature)
```

复基带的噪声功率是实通带的 2 倍（双边谱密度 → 复基带完整噪声）。

## 二、关键参数体系

### 2.1 功率与能量

| 参数 | 符号 | 公式 | 单位 |
|------|------|------|------|
| 信号功率 | S 或 P | E[\|x(t)\|²] | W |
| 噪声功率 | N 或 σ² | E[\|n(t)\|²] | W |
| 噪声功率谱密度 | N₀ | N₀ = N/B (单边) | W/Hz |
| 每比特能量 | Eb | Eb = S/R = P/R | J |
| 每符号能量 | Es | Es = S/Rs | J |

### 2.2 信噪比的多种表示

```
SNR = S/N                     — 线性信噪比（功率比）
SNR_dB = 10·log₁₀(S/N)       — dB 信噪比

Eb/N₀ = (S/R) / (N/B) = (S·B)/(N·R) = SNR × (B/R)
                                                      ↑ 处理增益

Es/N₀ = SNR × (B/Rs)         — 每符号 SNR
       = Eb/N₀ × log₂(M)      — M 为调制阶数
```

### 2.3 典型 SNR 参考值

| 场景 | SNR_dB | SNR_linear | 频谱效率 η (bps/Hz) |
|------|--------|-----------|---------------------|
| GPS (信号在噪声之下) | -26 dB | 0.0025 | 0.005 |
| 深空通信 | -10 dB | 0.1 | 0.14 |
| 蜂窝小区边缘 | 0 dB | 1 | 1.0 |
| 典型 LTE | 10 dB | 10 | 3.46 |
| 良好覆盖 | 20 dB | 100 | 6.66 |
| 5G 近基站 | 30 dB | 1000 | 9.97 |
| 毫米波视距 | 40 dB | 10000 | 13.29 |

## 三、香农容量公式（AWGN）

### 3.1 核心公式

```
C = B · log₂(1 + S/N)     [bps]
  = B · log₂(1 + SNR)

频谱效率:
η = C/B = log₂(1 + SNR)    [bps/Hz]
```

### 3.2 无限带宽极限

```
C∞ = lim(B→∞) B·log₂(1 + S/(N₀·B))
    = (S/N₀)·log₂(e)
    ≈ 1.4427·S/N₀     [bps]

→ 即使带宽无限大，容量也是有限的！
→ 极限值取决于发射功率与噪声谱密度的比值
```

### 3.3 香农极限（能效极限）

```
可靠通信所需最小 Eb/N₀：

Eb/N₀ > ln(2) ≈ 0.693 → -1.59 dB

物理含义：
  每传输 1 bit 信息，至少需要 0.693 倍噪声谱密度的能量
  或者说：接收 1 bit 信息至少需要 -1.59 dB 的 Eb/N₀
```

## 四、频带利用率与功率效率的折衷

```
香农公式的 Eb/N₀ 形式：

η = log₂(1 + η·Eb/N₀)

⟹  Eb/N₀ = (2^η - 1) / η

       功率效率 (低 Eb/N₀ 好)
          ↑
          |   ╲
          |     ╲
          |       ╲
          |         ╲── 香农界
          └──────────────→ 频带效率 (高 η 好)

权衡：高 η 需要高 Eb/N₀
      低 Eb/N₀ 只能获得低 η
```

## 五、实际系统中的噪声

### 5.1 接收机噪声模型

```
总噪声功率 N = N_thermal + N_receiver

热噪声:  N_thermal = k·T·B
  k = 1.38×10⁻²³ J/K（玻尔兹曼常数）
  T ≈ 290K（室温）
  kT ≈ -174 dBm/Hz（室温下热噪声谱密度）

接收机噪声系数 NF:
  N_receiver = (F-1)·k·T·B
  F = 10^(NF/10)
  NF 典型值: 2-10 dB（取决于接收机质量）

总噪声: N = F·k·T·B
```

### 5.2 链路预算计算

```
接收功率 Pr (dBm) = Pt + Gt + Gr - Lp - Lmargin

其中：
  Pt: 发射功率 (dBm)
  Gt, Gr: 天线增益 (dBi)
  Lp: 路径损耗 (dB)
  Lmargin: 衰落余量 (dB)

接收 SNR (dB) = Pr - N(dBm) = Pr - (10·log₁₀(F·k·T·B) + 30)
```

## 六、AWGN 下的误码率（详细）

### 6.1 最优检测：匹配滤波器 + 最大似然

```
对于发送符号 sᵢ，接收信号 r 的最大似然检测：

  î = argmin_i |r - sᵢ|²   （最小欧氏距离）

  即：选星座图上距离接收点最近的符号
```

### 6.2 BER 公式（Q 函数形式）

| 调制 | BER 公式 | 备注 |
|------|---------|------|
| **BPSK** | BER = Q(√(2·Eb/N₀)) | 基准参考 |
| **QPSK** | BER ≈ Q(√(2·Eb/N₀)) | 近似同 BPSK |
| **DBPSK** | BER = (1/2)·exp(-Eb/N₀) | 差分，无需信道估计 |
| **M-PAM** | BER ≈ 2·(M-1)/(M·log₂M)·Q(√(6·log₂M·Eb/((M²-1)·N₀))) | |
| **M-QAM** | BER ≈ 4·(1-1/√M)/(log₂M)·Q(√(3·log₂M·Eb/((M-1)·N₀))) | 方形星座 |
| **M-PSK** | BER ≈ 2/log₂M·Q(√(2·log₂M·Eb/N₀)·sin(π/M)) | M≥4 |
| **FSK（非相干）** | BER ≈ (1/2)·exp(-Eb/(2N₀)) | 简单实现 |
| **GMSK** | 同 BPSK（近似） | GSM/蓝牙 |

### 6.3 Q 函数

```
Q(x) = (1/√(2π)) · ∫_x^∞ e^(-t²/2) dt

近似公式（Chernov 界）:
  Q(x) ≤ (1/2)·e^(-x²/2)        （上界）
  Q(x) ≈ (1/(x√(2π)))·e^(-x²/2)  （x 较大时精确）
```

### 6.4 例题

**题目**：BPSK 系统，要求 BER ≤ 10⁻⁵，求所需 Eb/N₀ (dB)。

**解**：
```
BER = 10⁻⁵ 时查 Q 函数表或解方程：
  Q(√(2·Eb/N₀)) = 10⁻⁵

反查 Q 函数（或 Q^(-1)）: Q(4.26) ≈ 10⁻⁵
  √(2·Eb/N₀) = 4.26
  Eb/N₀ = 4.26²/2 = 9.07 → 9.58 dB

对比香农极限 -1.59 dB：
  BPSK 距极限约 11.17 dB —— 这就是编码的进步空间
```

## 七、从 AWGN 到实际信道

| 实际信道 | 与 AWGN 的差异 | 影响 |
|---------|--------------|------|
| **多径衰落** | 信道增益时变 | 需要分集/均衡 |
| **频率选择性** | 不同频点增益不同 | 需要 OFDM/均衡 |
| **干扰受限** | 不仅热噪声，还有同信道干扰 | 功率控制、ICIC |
| **相位噪声** | 振荡器不理想引入相位抖动 | 影响高阶 QAM |
| **非线性失真** | 功放饱和引入 | 需要数字预失真 (DPD) |
| **脉冲噪声** | 电力线/工业场景 | 需要非高斯解码 |
