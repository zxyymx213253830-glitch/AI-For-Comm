# 网络信息论与多用户信道

## 别名
Network Information Theory、多用户信息论、Multi-user Information Theory、MAC、BC、Relay Channel、Interference Channel

---

## 概述

经典信息论（香农 1948）研究的是**单发射机 → 单接收机**的点对点通信。网络信息论将其扩展到多用户场景——这是 5G/6G 多天线、协作通信、认知无线电的理论基础。

```
网络信息论的两大核心问题：

1. 容量区域 (Capacity Region)
   → 所有用户同时可达的速率组合 (R₁, R₂, ..., Rₖ)

2. 可达方案 (Achievability Scheme)
   → 什么样的编码/解码策略能到达容量区域边界
```

## 一、多址接入信道 (MAC: Multiple Access Channel)

### 1.1 系统模型

```
用户1 ──→ X₁ ──┐
                 ├──→ Y ──→ 接收机
用户2 ──→ X₂ ──┘
        ↑噪声 Z ~ N(0,N)
```

多个用户同时向一个接收机发送信息。

### 1.2 容量区域

对于两用户高斯 MAC：

```
R₁ < C(S₁/N)        = log₂(1 + S₁/N)
R₂ < C(S₂/N)        = log₂(1 + S₂/N)
R₁ + R₂ < C((S₁+S₂)/N) = log₂(1 + (S₁+S₂)/N)
```

容量区域是一个**截角多边形**（五边形）。

### 1.3 关键洞察

| 策略 | 说明 | 适用 |
|------|------|------|
| **逐次干扰消除 (SIC)** | 先解码强用户，减去其信号，再解码弱用户 | 到达容量区域的角点 |
| **时间共享** | 两个用户分时使用信道 | 连接角点的直线段 |
| **联合典型解码** | 同时解码所有用户 | 理论证明基础 |

### 1.4 例题

**题目**：两个用户共享 AWGN 信道，S₁/N = 10, S₂/N = 5（线性值）。求容量区域。

**解**：
```
R₁ < log₂(1 + 10) = log₂(11) ≈ 3.46 bps/Hz
R₂ < log₂(1 + 5)  = log₂(6)  ≈ 2.58 bps/Hz
R₁ + R₂ < log₂(1 + 15) = log₂(16) = 4.00 bps/Hz

角点 A: R₁ = 3.46, R₂ = 0.54 (先解用户 2，再解用户 1)
角点 B: R₁ = 1.42, R₂ = 2.58 (先解用户 1，再解用户 2)
```

## 二、广播信道 (BC: Broadcast Channel)

### 2.1 系统模型

```
                ┌──→ Y₁ ──→ 用户1
发射机 ──→ X ──┤
                └──→ Y₂ ──→ 用户2
```

一个发射机向多个用户发送不同信息。例如：基站同时服务多个手机。

### 2.2 叠加编码

核心策略——**叠加编码 (Superposition Coding)**：

```
发射信号 X = X₁ + X₂
         = (用户1信号) + (用户2信号)

信道条件假设：用户 1 信道更好（S₁ > S₂）

好的用户 (用户1)：
  1. 先解码 X₂（坏用户信号）
  2. 用 SIC 消除 X₂
  3. 再解码自己的 X₁

差的用户 (用户2)：
  1. 把 X₁ 当噪声
  2. 直接解码自己的 X₂
```

### 2.3 容量区域（退化高斯 BC）

```
R₂ < log₂(1 + α·S₂ / (α·S₁ + N))   — 坏用户速率
R₁ < log₂(1 + (1-α)·S₁ / N)        — 好用户速率

其中 α ∈ [0,1] 是功率分配因子
```

### 2.4 物理层应用：NOMA

| 传统 OMA | NOMA |
|----------|------|
| 每个用户独占时间/频率资源 | 多个用户叠加在同一资源上 |
| 容量 = 时分/频分区域 | 容量 = BC 容量区域（更大） |
| 4G LTE 采用 | 5G NR 候选技术 |

## 三、中继信道 (Relay Channel)

### 3.1 系统模型

```
源 ──→ 中继 ──→ 目的
  │              ↑
  └──────────────┘
     直传链路 (可选)
```

### 3.2 常见中继策略

| 策略 | 英文 | 操作方式 |
|------|------|---------|
| **放大转发** | AF (Amplify-and-Forward) | 中继直接放大接收信号并转发 |
| **解码转发** | DF (Decode-and-Forward) | 中继先解码再重新编码转发 |
| **压缩转发** | CF (Compress-and-Forward) | 中继压缩接收信号后转发 |
| **量化转发** | QF (Quantize-and-Forward) | CF 的离散版本 |

### 3.3 容量下界（DF 可达速率）

```
R < max min { log₂(1 + S₁/N₁), log₂(1 + S₂/N₂ + Sd/Nd) }
      p(x,xr)

其中：S₁ = 源→中继链路
      S₂ = 中继→目的链路
      Sd = 源→目的直传链路
```

## 四、干扰信道 (Interference Channel)

### 4.1 系统模型

```
发送机1 ──→ X₁ ──→ [信道] ──→ Y₁ ──→ 接收机1
                        ↗ (干扰)
发送机2 ──→ X₂ ──→ [信道] ──→ Y₂ ──→ 接收机2
```

两对收发机互相干扰。这是蜂窝网络中**最核心的模型**——相邻基站对小区边缘用户的干扰。

### 4.2 经典结果（Han-Kobayashi, 1981）

- 容量区域的精确刻画**至今仍是开放问题**（仅两用户高斯干扰信道）
- 最佳已知策略：**部分干扰消除**——每个接收机把干扰拆成"公共部分"和"私有部分"，解码公共部分并消除

### 4.3 五种处理干扰的方案

| 方案 | 策略 | 适用场景 |
|------|------|---------|
| 1. 把干扰当噪声 | 不解码干扰 | 干扰弱时 |
| 2. 正交化 | 时分/频分 | 简单但效率低 |
| 3. 解码干扰后消除 | SIC | 干扰强时（近远效应） |
| 4. 干扰对齐 (IA) | 在接收端将干扰对齐到低维子空间 | 高 SNR、多天线 |
| 5. 协作 | BS 间协作 (CoMP) | 5G 标准化方案 |

### 4.4 干扰对齐 (Interference Alignment)

思想：通过**预编码设计**使多个干扰源在接收端落在同一信号子空间内，释放更多维度给期望信号。

```
自由度的渐进上界 (K用户干扰信道):
  DoF ≤ K/2 (每个用户 1/2 自由度, Cadambe & Jafar, 2008)

这意味着：不需要正交化，所有用户可以同时传输，
每个用户获得一半的信道资源！
```

## 五、退化与高斯的黄金法则

### 5.1 退化信道 (Degraded Channel)

若 Y₁ 是 Y₂ 的退化版本（即 X → Y₂ → Y₁ 构成马尔可夫链），则称该 BC 为退化 BC。

### 5.2 高斯情形下的自动退化

**重要**：高斯 BC 天然具有退化性——加噪更多的信道是加噪更少信道的退化版本。因此高斯 BC 的容量区域是已知的（通过叠加编码可达）。

### 5.3 MAC-BC 对偶性

```
高斯 MAC 的容量区域  ≡  高斯 BC 的容量区域
(功率约束相同, 噪声相同)

→ 上行链路 (MAC) 和下行链路 (BC) 的容量区域
  在功率和噪声对称时是等价的！
```

## 六、5G/6G 中的网络信息论应用

| 5G 技术 | 对应的信息论模型 | 关键问题 |
|---------|---------------|---------|
| **MIMO/大规模 MIMO** | MIMO BC / MAC | 多天线下的容量区域、预编码设计 |
| **CoMP** | 协作通信 / 分布式天线 | 基站间有限前传容量下的协作 |
| **NOMA** | 广播信道 + 叠加编码 | 用户配对、功率分配 |
| **全双工** | 同时同频双向信道 | 自干扰消除后的容量增益 |
| **URLLC** | 有限块长信息论 | 短包传输下的可达速率 |
| **RIS/智能超表面** | 可控无源中继信道 | 相位配置下的信道容量优化 |
| **语义通信** | 率失真 + AI | 语义层面的信息压缩极限 |
